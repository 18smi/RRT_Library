RRT_Visualiser.h relies on SFML 3.0.2

to preform RRT_Visualiser::drawProject() you need to define bounds through RRT_Visualiser::setGeometricBounds() or RRT_Visualiser::estimateGeometricBounds()

create your own sampling strategy, distance calculation or obstacle via there base class (Implementation_Information gives all information needed)

The root node of every tree uses root_index (UINT_MAX) as its parent

all state space points are defined as a std::vector<double>
all geometric positions are defined as std::array<double, 3>

path is a vector of points that starts with the start point and ends with the end point

The SafetySettings struct controls how finely the system interpolates between two states and
the safety margin that is applied during collision checking

System::validSegment() uses PointsToPath and StateToGeometry to check movement from start to end against constraints and obstacles

note = Improved RRT* relights on specific cost so initialisation could be simplified (look into it)
note = adjustment radius for RRT* and Informed_RRT* are fixed as it seems to work best

--------------- ARCHITECTURE ---------------
RRT -
- System
- start point (std::vector<double>)
- end point (std::vector<double>)
- max extend (double)
- SamplingStrategy
- DistanceStrategy
- CostFunction (if needed)

System -
- min bound (std::vector<double>)
- max bound (std::vector<double>)
- wrapping (std::vector<bool>)
- StateToGeometry
- PointsToPath
- SafetySettings

SafetySettings -
- safety margin for the constraints (double)
- safety margin for the obstacles (double)
- interpolation steps (unsigned int)


------------ Key Concepts ------------
State Space - N dimension planing space represented by std::vector<double>
Constraint - a forbidden region in state space
Point - a state space location
Geometric Space - the physical 3D world represented by std::array<double,3>
Obstacle - a physical obstacle (forbidden region) in geometric space
Position - a geometric space location
PointsToPath - converts 2 state space points into a state space continues path
StateToGeometry - converts a state space point into 3 levels of bounding areas (axis aligned bounding box, capsule, SDF)
